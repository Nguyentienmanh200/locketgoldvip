# Locket Gold VIP

Hệ thống bán & kích hoạt **Locket Gold** bảo mật cao cấp.

- **Stack:** Next.js 16 + TypeScript + Tailwind CSS
- **Tính năng:** Admin Dashboard, Đăng ký CTV, Zalo Bot ready, Thanh toán Sepay
- **Bảo mật:** Zero-trust, Rate limiting, Argon2, CSP, Audit log...

## Domain

- Production: `locketgoldvip.vercel.app` (hoặc custom domain)

## Development

```bash
npm install
npm run dev
```

## Deploy

Tự động deploy qua Vercel khi push lên `main`.
